# Amrutha SM Portfolio

## Run
npm install
npm run dev

## Before deploying
- Put your resume PDF at `public/Amrutha_SM_Resume.pdf`
- Replace `YOUR_EMAIL@example.com` in `src/main.jsx`
- Replace the LinkedIn URL with your profile
- Replace `#` GitHub links with real repositories
- Add live demo links when available

## Build
npm run build
